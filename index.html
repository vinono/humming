Bun-first BFF core v0.1.0

Build a small BFF on Bun without dragging in a full framework.

Humming keeps the core deliberately narrow: health, options, and forward. Compose auth, cache, and metrics through a reactive plugin mesh.

$ bunx humming init my-bff

官方插件

开箱即用的插件矩阵

模块化、可摇树优化的官方插件，一行代码即插即用。

Auth Guard @humming/auth

Bearer token verification, JWKS validation, and RBAC claim assertion.

v0.1.0Official
Memory & Redis Cache @humming/cache

TTL-based response caching with stale-while-revalidate and Redis adapter.

v0.1.0Official
Circuit Breaker @humming/breaker

Automatic fallback handling with rolling failure window and half-open probes.

v0.1.0Official
CORS Handler @humming/cors

Granular cross-origin resource sharing rules with dynamic origin matching.

v0.1.0Official
Header Transform @humming/headers

TraceId propagation, client IP extraction, and upstream request header injection.

v0.1.0Official
Prometheus Metrics @humming/prometheus

Native /metrics endpoint exposing histogram percentiles, status codes, and RPS.

v0.1.0Official
Rate Limiter @humming/ratelimit

Sliding window algorithm per IP/Token with standard 429 Retry-After headers.

v0.1.0Official
Response Morph @humming/morph

Body transformation, field masking, and camelCase/snake_case schema adaptation.
